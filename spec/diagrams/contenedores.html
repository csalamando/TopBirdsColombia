Decisión de stack (ADR-001)
  • FastAPI + React SPA con contrato OpenAPI como interfaz desacoplada.
  • Todo el radar del stack está en ADOPT (FastAPI, React, TS, SQLite, pytest, Vitest, Playwright).
  • MSW simula el backend en desarrollo y en los tests unitarios del frontend.
NFR y deuda técnica
  • Rendimiento: respuesta API < 200ms p95 en endpoints de juego.
  • SQLite es suficiente para la demo (SLO 95%); migrar a Postgres si escala.
  • Hot-seat sin autenticación: limitado a un dispositivo.
