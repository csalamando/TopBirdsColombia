# Glosario — Top Trumps Aves de Colombia

## Términos del dominio

### Baraja
Conjunto completo de cartas disponibles para jugar. En el MVP, la baraja contiene ≥52 aves de Colombia.

### Carta
Representación de un ave con su nombre, imagen, atributos comparables y metadatos científicos.

### Atributo
Cualquiera de las seis características numéricas comparables de una carta: tamaño, peso, envergadura, velocidad, esperanza de vida, rareza.

### Ronda
Una jugada en la que ambos jugadores compiten comparando un atributo elegido por el jugador con el turno.

### Partida
Conjunto de rondas que comienza con el reparto de cartas y termina cuando un jugador acumula todas las cartas.

### Turno
Momento en el que un jugador tiene derecho a elegir el atributo a comparar en la ronda.

### IA (modo un jugador)
Oponente automatizado que selecciona atributos y resuelve rondas cuando le corresponde el turno.

### Hot-seat
Modo de dos jugadores humanos que comparten el mismo dispositivo y alternan turnos sin persistencia remota.

### Reserva (pila de empate)
Pila temporal donde se acumulan las cartas de rondas empatadas hasta que un jugador gane una ronda posterior.

### Rareza
Índice del 1 al 10 que indica qué tan difícil es avistar el ave en Colombia; no es un atributo físico.

### Fuente abierta
Fuente de datos cuya licencia permite reutilización con atribución (p. ej. Wikipedia, eBird, Wikidata).

## Términos técnicos

### FastAPI
Framework Python para construir APIs REST con tipado automático y documentación OpenAPI.

### OpenAPI
Especificación estándar para describir contratos de API REST.

### MSW (Mock Service Worker)
Librería para interceptar y simular respuestas de API en el navegador durante desarrollo y tests.

### Contract testing
Pruebas que validan que el cliente y el servidor cumplen el contrato OpenAPI acordado.
