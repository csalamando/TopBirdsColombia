Riesgos aceptados

  • PYSEC-2026-1845 (pytest): riesgo local de denegación de servicio en UNIX mediante /tmp/pytest-of-{user}. La demo corre en Windows local y el entorno de CI no persistirá datos sensibles en /tmp.
  • Vulnerabilidades de starlette 0.38.6: requieren starlette>=1.0.1, versión incompatible con fastapi==0.115.0. La aplicación no expone StaticFiles con rutas de usuario, no acepta multipart/form-data ni HTTPEndpoint, y no realiza autorización basada en path; por tanto el riesgo residual es bajo para un demo sin datos críticos.
  • SR-03 / SR-04 / SR-05: headers de seguridad, HTTPS y rate limiting se implementarán en el pipeline de despliegue (Sprint 13).
